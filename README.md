# Carolyne Liang — Artist Portfolio

Static, multi-page portfolio for composer and sound artist Carolyne (Chuowen) Liang. Built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Local preview

```bash
node serve.mjs
```

Open `http://localhost:8000`.

This server supports byte-range requests, allowing audio and video timelines to seek before the complete media file has downloaded.

## Pages

- `/index.html` — Home, about, selected projects, and contact
- `/projects.html` — Installation and multichannel audiovisual archive
- `/installation-entangled-voices.html` — Entangled Voices
- `/installation-hills-like-white-elephants.html` — Hills Like White Elephants
- `/installation-who-cares-if-you-listen.html` — Who Cares If You Listen
- `/installation-extensions-of-soil.html` — Extensions of Soil
- `/music.html` — Music archive and custom audio players
- `/project-demo-reel.html`, `/project-utopia.html`, `/project-searching.html`, `/project-agbogbloshie.html` — project details

`works.html` redirects old links to `projects.html`.
