# Carolyne Liang — Artist Portfolio

Static, multi-page portfolio for composer and sound artist Carolyne (Chuowen) Liang. Built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Local preview

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Pages

- `/index.html` — Home, about, selected projects, and contact
- `/projects.html` — Filterable project archive
- `/music.html` — Music archive and custom audio players
- `/project-demo-reel.html`, `/project-utopia.html`, `/project-searching.html`, `/project-agbogbloshie.html` — project details

`works.html` redirects old links to `projects.html`.
